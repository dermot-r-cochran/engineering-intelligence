# Documentation

Engineering Intelligence examines how people, AI, repositories, and knowledge practices can improve the quality of engineering and other forms of inquiry. These pages are an evolving set of concepts and practical questions, not a claim that any one method works in every setting.

## Topics

- [Engineering intelligence](engineering-intelligence.md) — a framing for improving decisions and outcomes through evidence, context, and feedback.
- [Human-AI systems](human-ai-systems.md) — collaboration, roles, oversight, and accountability when people work with AI.
- [AI evaluation](ai-evaluation.md) — methods for checking capability, reliability, safety, and usefulness.
- [Repository-aware development](repository-aware-development.md) — understanding a codebase as both a technical system and a record of decisions.
- [Context engineering](context-engineering.md) — curating the information, tools, and constraints available to an AI system.
- [Natural language programming](natural-language-programming.md) — using natural language to specify and shape computational work.
- [Virtual anthropology](virtual-anthropology.md) — observing practices, norms, and relationships in digital environments.

## Evidence

[Where this is practised](evidence.md) maps every topic to a repository that already applies it, so each principle can be checked against a record rather than taken on trust.

## Suggested paths

- **Building with AI:** Start with [human-AI systems](human-ai-systems.md), then read [context engineering](context-engineering.md) and [AI evaluation](ai-evaluation.md).
- **Working in an existing codebase:** Start with [repository-aware development](repository-aware-development.md), then consider [natural language programming](natural-language-programming.md).
- **Understanding people and systems:** Start with [engineering intelligence](engineering-intelligence.md) and [virtual anthropology](virtual-anthropology.md).

## Shared principles

Across topics, prefer evidence to assertion, evaluation to hype, useful context to isolated prompts, and human judgment to unreviewed automation. Treat repositories as knowledge systems, favor practical usefulness over novelty, and communicate clearly.
