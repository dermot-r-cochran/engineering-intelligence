# Engineering Intelligence

Engineering Intelligence explores how people, repositories, knowledge systems, evaluation frameworks, and AI can work together to improve engineering, research, creativity, and decision-making.

This repository is a knowledge system first and a software project second. It favors evidence over assertion, evaluation over hype, context over isolated prompts, and human judgment over automation. It treats repositories as knowledge systems and values practical usefulness and clear writing over novelty and jargon.
